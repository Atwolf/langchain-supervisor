# LangChain Supervisor

This workspace exposes two interaction paths:

- Use the agent mode picker for conversational routing through the supervisor and registered sub-agents.
- Click **Architecture QA Wizard** to collect system, component, data, messaging, and integration details into a target JSON model.

The QA wizard is action-driven and starts immediately from its card. Its output is normalized server-side and stored only for the current Chainlit session.
